## 一句话简介

Caelum 是一款集打卡、随手记账、时间管理、成绩分析于一体的移动生活助手。

## 版本描述（可直接用于小程序后台提交）

> Caelum 生活助手正式上线。提供打卡、随手记账、时间管理局、成绩分析、资料管理、提醒管理等功能，支持多主题皮肤与消息推送，帮助您高效管理日常事务与个人数据。

## 功能清单

### 1. 打卡
- 定位打卡，自动区分工作日与节假日
- 基于地理围栏自动判定内勤 / 外勤

### 2. 随手记
- 收支记录，费用分类（餐饮 / 交通 / 购物 / 娱乐 / 医疗 / 住房 / 其他）
- 明细查询与统计

### 3. 时间管理局
- 每日时间记录
- 堆叠柱状图统计分析

### 4. 成绩分析
- 成绩记录与多维度分析

### 5. 提醒管理
- 提醒事项的新增、编辑、删除与查询

### 6. 资料库管理
- 文档资料的新增、编辑、预览

### 7. 个人中心
- 头像 / 资料编辑、密码修改
- 消息通知、应用设置、常见问题、关于我们

### 8. 主题皮肤
- 多主题切换（经典蓝 / 粉白 / 库洛米 / 初音未来）

### 9. 消息推送
- UniPush 消息通知
